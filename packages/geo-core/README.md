# @headless-geo/core

CMS-agnostic core of [Headless GEO](https://github.com/echoatgrs/geo-plugin): AI crawler detection, IP verification against vendor-published ranges, hit ingestion, llms.txt builders, rich text to Markdown, and dashboard stats.

You usually don't install this directly. Use [`payload-plugin-geo`](https://www.npmjs.com/package/payload-plugin-geo) or [`strapi-plugin-geo`](https://www.npmjs.com/package/strapi-plugin-geo) with [`@headless-geo/next`](https://www.npmjs.com/package/@headless-geo/next).
